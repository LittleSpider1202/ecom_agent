# 设计阶段 (design)

## 阶段目标
解构问题，确认怎么做

## 角色视角
产品架构师

## 核心理念
> 设计 Agent 的本质是设计一套**问题解决机制**，而非功能模块。
> 目标是让系统在持续使用中**自我进化**，处理能力越来越强。

## 关注点
- 系统目标与路径
- 核心机制（执行、问题识别、问题归类、方案匹配、知识沉淀）
- 评价体系（多维度：总体/分类/个体）
- 优化回路（问题如何暴露、归因、闭环修复）
- 交互设计
- 数据设计

## 模式
🔒 **Plan 模式** - 只设计、不写代码

## 产出物
PRD（产品需求文档）

## 文件命名规范
- `prd-v{版本号}.md` - 产品需求文档

## 输入依赖
基于 `req/` 目录下的 MRD 文档
