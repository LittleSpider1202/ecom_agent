# 测试阶段 (test)

## 阶段目标
投放验证，验证市场

## 角色视角
产品运营

## 关注点
- PMF验证指标
- 用户反馈收集
- 迭代方向决策

## 双向验证
**自顶向下：目标体系监控**
- 总目标是否达成？
- 子目标拆解验证

**自底向上：问题识别与处置**
- 问题是否被有效暴露？
- 问题是否被正确归因？
- 问题是否按设计的回路修复？

## 产出物
- 验证报告
- 用户反馈汇总
- 下一轮迭代需求

## 文件命名规范
- `report-v{版本号}.md` - 验证报告
- `feedback-v{版本号}.md` - 用户反馈汇总

## 输入依赖
基于 `design/` 目录下的 PRD 文档中的评价体系进行验证
